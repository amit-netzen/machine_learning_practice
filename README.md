🚀 Getting Started

Clone the repository:

git clone https://github.com/amit-netzen/machine_learning_practice.git
cd machine_learning_practice

Install the commonly used dependencies:

pip install numpy pandas matplotlib seaborn scikit-learn xgboost jupyter

Start Jupyter Notebook:

jupyter notebook

Then open the notebook you want to explore.
